# DeepSeekV4.1-Flash-HiFloat8 量化Agent实践

AMCT面向昇腾平台提供从模型接入、量化方案选择、量化实验、精度验证到部署权重导出的完整流程。通过 Agent 工作流，AMCT可以结合已有 Casebook 自动推荐方案、调用量化工具执行实验，并将方案与过程沉淀为可复用资产。

## 1. 背景与目标

将原始模型权重转换为昇腾平台可直接部署的量化权重，通常涉及模型结构分析、量化算法选择、精度评测、权重格式转换和部署适配等多个步骤。传统流程依赖人工经验，试错成本高，且成功方案不易复用。

AMCT Agent 的目标是将上述过程编排为可追踪的自动化工作流：

> 模型接入 → 能力检查 → 方案推荐 → 自动量化 → 精度验证 → 权重导出 → 经验沉淀

## 2. Agent 工作流与模块架构

<img src="assets/agent-workflow.png" alt="AMCT Agent 模块关系图" width="70%">

### 2.1 Model Adapter

Model Adapter 负责新模型接入，主要包括：

- 模型注册与结构适配；
- BF16 基线测试；
- 关闭量化后的浮点等价测试；
- 最小 PTQ 冒烟验证。

该模块的职责是确认模型能够在量化链路中稳定运行，并为后续精度比较建立可信基线。

### 2.2 Model Quantization

Model Quantization 负责量化阶段总控，主要包括：

- **量化方案推荐**：根据 Casebook 推荐可行方案，也支持用户指定方案；
- **直转量化评测**：基于已有方案进行快速转换和评测；
- **量化算法推荐及验证**：推荐候选算法并自动完成验证；
- **量化权重导出**：生成部署权重和方案说明文档。

### 2.3 Casebook 与 Quant Tools

Casebook 保存历史模型、量化配置、实验轨迹和评测结果，为 Agent 提供可检索的经验依据。Quant Tools 负责具体的量化实验、算法执行、精度评测和部署格式导出。二者结合后，Agent 可以完成从决策到执行的闭环，并持续积累后续任务可复用的知识。

## 3. 端到端流程

### 3.1 使用场景识别

明确原始权重、目标昇腾硬件、目标量化格式和部署运行时，确认最终交付物为可加载的量化权重及其方案说明。

### 3.2 方案选择

检查模型是否已经适配、是否存在参考方案，以及目标算子和量化格式是否可用。Agent 可根据 Casebook 推荐量化方式，也可接受用户指定配置。

### 3.3 量化实施与验证

调用 Quant Tools 执行量化实验，对比 BF16 基线并分析精度变化。对于异常结果，保留配置和轨迹，便于定位问题与重复实验。

### 3.4 交付与沉淀

导出部署权重、量化配置和方案说明文档，并将验证通过的方案及过程更新至 Casebook，形成后续模型适配的复用资产。

## 4. DSV4.1-Flash-HiFloat8 实践

本实践验证了从 AMCT 离线量化到 vLLM-ascend 部署评测的完整通路。

```text
官方权重（块状 FP8）
      ↓
AMCT 离线量化（HiFloat8）
      ↓
HiFloat8 权重落盘
      ↓
vLLM-ascend 加载部署
      ↓
AisBench 精度评测
```

### 4.1 权重转换与落盘

离线转换过程中，权重文件逐个读取，仅转换需要量化的权重，其余权重原样写回。核心逻辑包括模型转换、HiFloat8 量化、配置转换和端到端自测。该流程通过以下模板填报，可基于AMCT-Agent工作流自动化执行。

### 4.2 部署适配

基于官方 vLLM 版本，通过 uint8 数据格式透传 HiFloat8 数据格式，并打上适配补丁，使 vLLM-ascend 能够加载转换后的离线权重并进行推理部署。

### 4.3 精度结果

| 数据集 | BF16 | HiFloat8 | 变化 |
|---|---:|---:|---:|
| LiveCodeBench v5（pass@1） | 67.07 | 67.37 | +0.30 |
| LongBench-v2 | 47.51 | 47.32 | -0.19 |
| MATH-500 | 96.80 | 97.20 | +0.40 |
| CMMLU（acc） | 90.11 | 89.83 | -0.28 |
| MMLU-Pro（acc） | 83.98 | 84.25 | +0.27 |
| HumanEval+（pass@1） | 91.46 | 91.46 | 0.00 |
| GPQA-Diamond | 76.77 | 76.77 | 0.00 |

结果显示，HiFloat8 与 BF16 整体效果接近，主要指标变化在合理范围内，验证了量化、权重加载和评测链路的正确性。同时HiFloat8能够在保持模型能力的同时，为大模型在昇腾平台上的高效部署提供了一种高精度，低位宽的量化选择。

## 5. 流程优势

### 易用性

将模型适配、量化、算法优化和部署导出整合到统一流程中，降低开发者的使用门槛。

### 上下文效率

通过 Repo-Map 聚焦关键锚点文件，新模型或新算法导入时无需扫描全部代码，减少 Agent 的上下文消耗。

### 可复用性

将方案、轨迹和结果沉淀到 Casebook，使一次成功实验能够服务于后续模型和任务。

### 可验证性

通过 BF16 基线、浮点等价测试、PTQ 冒烟和 AisBench 评测，确保量化结果和部署通路可验证、可追踪。

## 6. 结论

AMCT Agent 将模型量化从分散的人工操作转变为可理解、可执行、可验证、可复用的自动化工作流。本实践已打通 AMCT 离线量化、HiFloat8 权重落盘、vLLM-ascend 部署和 AisBench 评测的完整链路，为昇腾平台上的模型压缩与推理部署提供了可落地的技术路径。
