## W4A4 精度评估 —— 优化结果汇报

按评审要求补齐了 W4A4（权重 + 激活均 MXFP4）实现，并做了系统优化与消融。汇报结果与当前进展。

### 一、实现

amct 量化类型组合表中无 MXFP4 的 W4A4 组合（仅 `NOT_QUANTIZE mxfp4_e2m1` weight-only），故在自定义算子的 `fake_quant_forward` 中，对旋转后的激活做逐 token、逐 32 通道的动态 MXFP4，实现激活 + 权重双低比特。

### 二、优化与消融

Qwen3-8B，seq_len=4096，前 20 块快速消融（基准 bf16@20 块 = 8.3880）：

| 方案 | PPL | delta |
|---|---|---|
| W4A4 无旋转 | 9.1913 | 0.803 |
| + block Hadamard 旋转 (k=128) | 9.0920 | 0.704 |
| + 激活 scale-fitting + 联合补偿 | 9.0527 | 0.665 |
| + 旋转加强 (k=4096) | 8.9876 | 0.600 |
| + 保护 down_proj 激活 | 8.9335 | 0.546 |
| + 保护 o_proj 激活 | 8.8455 | **0.458** |
| + 激活 scale 裁剪搜索 | 8.8566 | 0.469（**负结果，已弃用**） |

其中两项值得说明：

- **旋转块大小可调（k=4096）**：论文取 k=128 是**在线旋转算子开销**的权衡；本任务为 fake-quant 精度评估、旋转无推理开销，故把 k 放开为可调参数。实测从 128 增至 4096 再收 0.065，印证"摊开离群值"的机理。此为论文未做的消融。
- **激活 scale 裁剪搜索（负结果）**：逐块搜索裁剪系数以最小化量化 MSE（候选含 1.0，故 MSE 意义上不可能变差），实测 PPL 反升 0.011。原因是被裁剪的大激活（massive activation）功能上承担 attention sink，属模型有效零件而非噪声，**逐块 MSE 最优 ≠ 端到端最优**。该实验排除了"剩余误差源于 scale 未调优"的假设。

### 三、最终精度

Qwen3-8B，seq_len=4096，全量 73 块，对比 bf16 PPL 8.9893：

| 方案 | 权重 | 激活 | PPL | delta |
|---|---|---|---|---|
| W4A16（主线） | mxfp4 | bf16 | 9.2621 | **0.273** ✅ |
| W4A4 优化前（k=128） | mxfp4 | mxfp4 | 9.7520 | 0.763 |
| **W4A4 优化后** | mxfp4 | mxfp4（混合精度） | **9.4356** | **0.446** |

优化将 W4A4 的 delta 从 0.763 降至 0.446（**降低 42%**），但**距 0.4 门槛尚差 0.046，未达标**，如实汇报。

**混合精度的算力口径**：保护 o_proj + down_proj 两类层的激活。按层数计，仍有 71.4% 的层跑真 4-bit 激活；但按 FLOPs 计，这两类层占每层 67.1M/192.9M ≈ **34.8% 的 matmul 算力退回 A16**——按"计算收益"口径应以后者为准，一并说明。权重全程 MXFP4，量化层占比（99.6%）与显存收益（67.4%）不受影响。

### 四、关于是否继续压低

我们也做了横向量级参照（详见报告 §4.3 ④），但需说明：公开 W4A4 工作多采用 **per-channel INT4 权重**（整行共享 1 个 scale）且为全量 W4A4，与本工作的 **MXFP4 block-32**（每行 128 个 scale）+ 混合精度**配置并不对等**，差异对本工作有利，因此**不能据此声称优于已有方法，也不能据此论证 0.4 不可达**。

就本项目已投入的手段，0.446 是收敛点，已排除的方向有实验依据：5 项有效手段边际收益明显递减；裁剪搜索为负结果，指向剩余误差来自 E2M1 每元素仅 16 个量化级的本征容量。我们**不打算继续增加保护层**——那会进一步侵蚀真 4-bit 算力占比，本质向 W4A8 漂移，与评估 W4A4 计算收益的目的相悖。

继续压低需**架构级改造**：全宽残差流旋转（QuaRot R1 式，含非幂次 Kronecker Hadamard）或可学习变换（SpinQuant / LATMiX）。
