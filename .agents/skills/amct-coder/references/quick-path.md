# 快速路径：普通局部 bug 修复

## 加载时机

SKILL.md 入口处的条件命中时读取本文件（已知道改哪个文件、改的是行为实现 bug、不新增 dtype/算法/solver、不动 CLI 参数和公开接口）。诊断/review/规划、新功能、跨模块、动契约的任务不适用本文件，走 SKILL.md 完整流程。

## 最低动作集合

```text
1. 定位：rg 符号 → 读目标函数与直接调用方（通常 ≤3 个锚点）
2. 判级：符合入口条件即轻级；执行中发现要改更多文件/动接口 → 转标准级，
   回 SKILL.md「核心流程」，已读资料复用
3. 改：按 coding-rules 对应节（错误文案/日志/边界处理），不整读
4. 验：py_compile + ruff（改动文件）+ 目标单测；失败按 validation.md
   「验证失败的处理」分类处置
5. 交付：一句话分级 + 改了什么 + 验证结果
```

## 不需要做的事

- 不读 repo-map、不声明边界（轻级豁免）。
- 不读 process-rules、walkthrough、主手册——普通修复直接读源码定位，快照核对只在引用手册快照事实作为落点依据时需要。
- 不预读其它 reference：遇到本文件没覆盖的情形，按 SKILL.md 核心流程和 Reference 导航补。

升级即离开本文件：判级从轻变标准的那一刻起，后续动作以 SKILL.md 为准。
