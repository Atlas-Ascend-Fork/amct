# 快速路径：普通局部 bug 修复

## 加载时机

[SKILL.md 首段「轻级直达卡」](../SKILL.md#轻级直达卡) 四条判据全中、且属普通修复（行为实现 bug）时读取本文件。判据以直达卡为唯一出处，本文件不复制。诊断/review/规划、新功能、跨模块、动契约的任务不适用本文件，走 SKILL.md 完整流程。

## 最低动作集合

```text
1. 定位：rg 符号 → 读目标函数与直接调用方（通常 ≤3 个锚点）
2. 判级：符合直达卡 ①~④ 即轻级；执行中发现要改更多文件/动接口 → 转标准级，
   回 SKILL.md「核心流程」，已读资料复用
3. 改：按 coding-rules 对应节（错误文案/日志/边界处理），不整读
4. 验：按 validation.md「按变更类型选验证」选最小验证（Python 改动通常落在
   「Python 局部实现」行）；失败按其「验证失败的处理」分类处置。
   清单以 validation.md 为准，本行只是索引，不是第二份清单
5. 交付：按 SKILL.md「交付格式」的『改了代码』清单（唯一出处）；不适用项写
   n/a，不整项省略
```

## 不需要做的事

- 不读 repo-map、不声明边界（轻级豁免）。
- 不读 process-rules、walkthrough、主手册，**也不读 SKILL.md 分界线之后的任何内容**（分级表、主手册豁免的依据、比例原则、分级示例）——①~④ 判据与主手册豁免的操作性规则都由 [SKILL.md 首段「轻级直达卡」](../SKILL.md#轻级直达卡) 承载，本文件自足。普通修复直接读源码定位，快照核对只在引用手册快照事实作为落点依据时需要。豁免只免读取，①~④ 与各 BLOCKER 仍适用。
- 不预读其它 reference：遇到本文件没覆盖的情形，按 SKILL.md「各级都要做」节和 Reference 导航补。

升级即离开本文件：判级从轻变标准的那一刻起，后续动作以 SKILL.md 为准。
