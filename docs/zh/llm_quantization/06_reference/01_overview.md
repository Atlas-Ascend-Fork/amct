# 参考文档概览

> 本目录集中提供 AMCT LLM 的命令、API、配置和输出产物参考。

## 文档目录

- [CLI 参考](02_cli.md)：命令、参数、默认值和执行约束。
- [Python API 参考](03_api.md)：公开 API、程序化调用和内部实现的边界。
- [配置参考](04_config.md)：bit 配置、部署配置和配置检查。
- [输出产物参考](05_artifacts.md)：PTQ 数据、PTQ 参数、部署权重和验证文件。

## 使用建议

先根据任务选择命令或配置参考，再结合输出产物确认执行结果。遇到运行错误时，转到 [问题排查](../07_troubleshooting/01_troubleshooting.md)。

## 版本约定

参数默认值、配置字段和产物格式必须以对应 GitCode 提交的源码、示例和验证结果为准。
