# Overall Constraints and API List

## Constraints

- If an API contains a parameter that requires user input of a file path, ensure that the input path is correct. AMCT does not perform security validation on the path.
- If an API contains a parameter that requires user input of a file path, when quantization is re-executed, the values related to this parameter will be overwritten. The quantization log will also contain a warning risk message indicating that the related file has been overwritten.

## API List

| Classification | API Name | Description |
| --- | --- | --- |
| Public APIs | [ModelEvaluator](./ModelEvaluator.md) | For a given model, based on the model's bin-type input data, provides a Python instance that can perform calibration and inference on the model as an evaluator. |
| Post-Training Quantization APIs | [quantize](quantize.md) | Converts a high-precision model into a calibration model to obtain a quantized calibration model, and computes quantization parameters after inference. |
| | [convert](convert.md) | Converts a quantized calibration model into a quantized deployment model. |
| | [algorithm\_register](algorithm_register.md) | Registers a user-provided custom algorithm with the AMCT tool. |
| | [create\_quant\_config](create_quant_config.md) | Post-training quantization API. Finds all quantizable layers based on the graph structure, automatically generates a quantization configuration file, and writes the quantization configuration information of the quantizable layers to the file. |
| | [quantize\_model](quantize_model.md) | Post-training quantization API. Performs quantization processing on the input graph structure to be quantized according to the given quantization configuration file, inserts operators related to weight quantization and data quantization into the passed-in graph structure, generates the quantization factor record file **record_file**, and returns the modified **torch.nn.Module** calibration model. |
| | [save\_model](save_model.md) | Post-training quantization API. Based on the quantization factor record file **record_file** and the modified model, inserts operators such as **AscendQuant** and **AscendDequant**, and then saves them as a **fake_quant** model that can perform accuracy simulation in the ONNX Runtime environment and a deployment model that can perform inference on the AI processor. |
| | [accuracy\_based\_auto\_calibration](accuracy_based_auto_calibration.md) | Performs an automatic calibration process based on the user-input model and configuration file, searches for a quantization configuration that meets the target accuracy, and outputs a **fake_quant** model that can perform accuracy simulation in the ONNX Runtime environment and a **deploy** model that can perform inference on the AI processor. |
| | [quantize\_preprocess](quantize_preprocess.md) | Quantization data equalization preprocessing API. Performs quantization processing on the input graph structure to be quantized according to the given quantization configuration file, inserts operators related to equalization quantization into the passed-in graph structure, generates the equalization quantization factor record file **record_file**, and returns the modified **torch.nn.Module** calibration model. |
| Quantization-Aware Training APIs | [create\_quant\_retrain\_config](create_quant_retrain_config.md) | Quantization-aware training API. Finds all quantizable layers based on the graph structure, automatically generates a quantization configuration file, and writes the quantization configuration information of the quantizable layers to the configuration file. |
| | [create\_quant\_retrain\_model](create_quant_retrain_model.md) | Quantization-aware training API. Performs quantization processing on the input graph structure to be quantized according to the given quantization configuration file, inserts quantization-related operators (quantization-aware training layers for data and weights, and the layer for finding N) into the passed-in graph structure, generates the quantization factor record file **record_file**, and returns the modified **torch.nn.Module** model that can be used for quantization-aware training. |
| | [restore\_quant\_retrain\_model](restore_quant_retrain_model.md) | Quantization-aware training API. Performs quantization processing on the input graph structure to be quantized according to the given quantization-aware training configuration file, inserts quantization-aware training-related operators (quantization-aware training layers for data and weights, and the layer for finding N) into the passed-in graph structure, generates the quantization factor record file **record_file**, loads the **checkpoint** weight parameters saved during training, and returns the modified **torch.nn.Module** quantization-aware training model. |
| | [save\_quant\_retrain\_model](save_quant_retrain_model.md) | Quantization-aware training API. Based on the user's final retrained model, inserts operators such as **AscendQuant** and **AscendDequant** to generate the final quantization accuracy simulation model and quantization deployment model. |
| Single-Operator Mode Quantization-Aware Training APIs | [Conv2dQAT](Conv2dQAT.md) | Constructs the QAT operator for **Conv2d**. |
| | [ConvTranspose2dQAT](ConvTranspose2dQAT.md) | Constructs the QAT operator for **ConvTranspose2d**. |
| | [Conv3dQAT](Conv3dQAT.md) | Constructs the QAT operator for **Conv3d**. |
| | [LinearQAT](LinearQAT.md) | Constructs the QAT operator for **Linear**. |
| Sparse APIs | [create\_prune\_retrain\_model](create_prune_retrain_model.md) | Channel sparsity or 4:2 structured sparsity API. Only one of the two sparsity features can be enabled at a time. Performs sparsity processing on the input graph structure to be sparsified according to the given sparsity configuration file, inserts or replaces related operators in the passed-in graph structure, generates the **record_file** that records sparsity information, and returns the modified **torch.nn.Module** model that can be used for post-sparsity training. |
| | [restore\_prune\_retrain\_model](restore_prune_retrain_model.md) | Channel sparsity or 4:2 structured sparsity API. Only one of the two sparsity features can be enabled at a time. Sparsifies the input graph structure to be sparsified according to the sparsity records in the given **record_file**, and returns the modified **torch.nn.Module** model that can be used for post-sparsity training. |
| | [save\_prune\_retrain\_model](save_prune_retrain_model.md) | Sparse API. Based on the user's final retrained sparse model, generates the final ONNX simulation model and deployment model. |
| Automatic Channel Sparsity Search APIs | [auto\_channel\_prune\_search](auto_channel_prune_search.md) | Automatic channel sparsity API. Calculates the sparsity sensitivity (affecting accuracy) and sparsity benefit (affecting performance) of each channel based on the user model, and then the search strategy searches for the optimal per-layer channel sparsity rate based on this input to balance accuracy and performance. Finally outputs a configuration file. |
| Combined Compression APIs | [create\_compressed\_retrain\_model](create_compressed_retrain_model.md) | Static combined compression API. Performs compression processing on the input model to be statically combined and compressed according to the given combined compression configuration file. That is, first sparsifies the passed-in model (channel sparsity or 4:2 structured sparsity, either one), then inserts quantization-related operators (quantization-aware training layers for data and weights, and the searchN layer) into the model, generates the sparsity and quantization factor record file **record_file** (if configured), and returns the modified **torch.nn.Module** model. |
| | [restore\_compressed\_retrain\_model](restore_compressed_retrain_model.md) | Static combined compression training API. Performs compression processing (sparsification first, then quantization) on the input model to be statically combined and compressed according to the given combined compression configuration file and record file, and loads the saved weights. Sparsifies the passed-in model according to the sparsity records in the given **record_file**, then inserts quantization-related operators (quantization-aware training layers for data and weights, and the searchN layer) into the model. Loads the **checkpoint** weight parameters saved during training, and returns the modified **torch.nn.Module** model. |
| | [save\_compressed\_retrain\_model](save_compressed_retrain_model.md) | Static combined compression API. Based on the user's final retrained model, generates the final static combined compression accuracy simulation model and deployment model. |
| Tensor Decomposition APIs | [auto\_decomposition](auto_decomposition.md) | Performs tensor decomposition on the user-input PyTorch model object to obtain the decomposed model object and the corresponding names of layers before and after decomposition, and saves the decomposition information file (optional). |
| | [decompose\_network](decompose_network.md) | Takes the user-input PyTorch model object and the decomposition information file saved through **auto_decomposition**, changes the model object to the tensor-decomposed structure according to the decomposition information file, and obtains the decomposed model object and the corresponding names of layers before and after decomposition. |
| Distillation APIs | [create\_distill\_config](create_distill_config.md) | Distillation API. Finds all distillable quantizable layers and distillable quantizable structures based on the graph structure, automatically generates a distillation quantization configuration file, and writes the quantization configuration and distillation structure of the distillable quantizable layers to the configuration file. |
| | [create\_distill\_model](create_distill_model.md) | Distillation API. Performs quantization processing on the input graph structure to be quantized and compressed according to the given distillation quantization configuration file, inserts quantization-related operators (distillation quantization layers for data and weights, and the layer for finding N) into the passed-in graph structure, and returns the modified **torch.nn.Module** model that can be used for distillation. |
| | [distill](distill.md) | Distillation API. Performs distillation processing on the input graph structure to be distilled according to the given distillation quantization configuration file, and returns the modified **torch.nn.Module** distillation model. |
| | [save\_distill\_model](save_distill_model.md) | Distillation API. Based on the user's final distilled model, generates the final quantization accuracy simulation model and quantization deployment model. |
| KV Cache Quantization APIs | [create\_quant\_cali\_config](create_quant_cali_config.md) | KV-cache quantization API. Generates the detailed quantization configuration for each layer based on the user-passed model, quantization layer information, and quantization configuration information. |
| | [create\_quant\_cali\_model](create_quant_cali_model.md) | KV-cache quantization API. Modifies the graph of the user model based on the model and the detailed quantization configuration, replacing the **Linear** operator to be quantized with a quantization operator that performs IFMR/HFMG quantization after output. The user then performs online calibration on the model, and after calibration, the generated quantization factors are saved in **record_file**. |
| | [QuantCalibrationOp](QuantCalibrationOp.md) | KV Cache quantization API. Used for user graph construction. During forward propagation, calls the IFMR/HFMG quantization algorithm to calibrate the output according to the user's quantization algorithm configuration. After calibration, outputs the quantization factors to the specified layer name in the **record_file** file in the corresponding format. |
| Structured Pruning APIs | [prune](prune.md) | Main entry for structured pruning. Performs in-place pruning on an instantiated **torch.nn.Module** (dense FFN intermediate dimension / CNN channels / MoE experts). When **tolerance** is passed, automatically searches for the maximum pruning rate that satisfies the accuracy tolerance. |
| | [prune\_finetune](prune_finetune.md) | Lightweight fine-tuning recovery after pruning (for use by the **finetune_fn** of accuracy search). Imported from `amct_pytorch.pruning` (not the top-level `amct.*`). |
| | [prune\_diagnose](prune_diagnose.md) | Pruning feasibility diagnosis (prunable targets / fixed-rate dry-run / accuracy search dry-run). Imported from `amct_pytorch.pruning` (not the top-level `amct.*`). |
