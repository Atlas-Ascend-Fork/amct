# Record File<a name="ZH-CN_TOPIC_0000002517028838"></a>

<!-- md-trans-meta sourceCommit=50092c1ff927c3d7fb95cc796b97264520f8a34e translatedAt=2026-10-16T08:51:06.773Z pushedAt=2026-11-05T01:12:03.437Z nl=2 -->

A record file is a serialized data structure file based on the protobuf protocol. It records the quantization factors scale/offset in quantization scenarios, the cascade relationships between sparse layers in sparsity scenarios, and so on. The compressed model file is generated by using this file, the compression configuration file, and the original network model file.

## Record Prototype<a name="section851092965013"></a>

The protobuf prototype definition corresponding to the record file is as follows (or see the **/amct\_pytorch/proto/scale\_offset\_record\_pytorch.proto** file in the *AMCT installation directory*):

```protobuf
syntax = "proto2";
import "amct_pytorch/proto/basic_info.proto";

message SingleLayerRecord {
    optional float scale_d = 1;
    optional int32 offset_d = 2;
    repeated float scale_w = 3;
    repeated int32 offset_w = 4;
    repeated uint32 shift_bit = 5;
    repeated float tensor_balance_factor = 6;
    optional bool skip_fusion = 9 [default = false];
    optional string dst_type = 10 [default = 'INT8'];
    optional string act_type = 11 [default = 'INT8'];
    optional string wts_type = 12 [default = 'INT8'];
    optional string fakequant_precision_mode = 13 [default = 'DEFAULT'];
    optional float scale_h = 21;
    optional int32 offset_h = 22;
    repeated float scale_r = 23;
    repeated int32 offset_r = 24;
}

message SingleLayerKVCacheRecord {
    repeated float scale = 1;
    repeated int32 offset = 2;
}

message MapFiledEntry {
    optional string key = 1;
    optional SingleLayerRecord value = 2;
    optional SingleLayerKVCacheRecord kv_cache_value = 3;

}

message ScaleOffsetRecord {
    repeated MapFiledEntry record = 1;
    repeated PruneRecord prune_record = 2;
}

message PruneRecord {
    repeated PruneNode producer = 1;
    repeated PruneNode consumer = 2;
    optional PruneNode selective_prune = 3;
}

message PruneNode {
    required string name = 1;
    repeated AMCTProto.AttrProto attr = 2;
}
```

## Record File<a name="section1850911716537"></a>

The format of the final generated record file is *record.txt*, and the file content is divided as follows based on different features.

- Record file for the quantization feature

    For general quantization layer configuration, the **scale\_d**, **offset\_d**, **scale\_w**, and **offset\_w** parameters need to be included. The file content example is as follows:

    ```protobuf
    record {
      key: "conv1"
      value {
        scale_d: 0.0798481479
        offset_d: 1
        scale_w: 0.00297622895
        offset_w: 0
        skip_fusion: true
        dst_type: "INT8"
      }
    }
    record {
      key: "layer1.0.conv1"
      value {
        scale_d: 0.00392156886
        offset_d: -128
        scale_w: 0.00106807391
        scale_w: 0.00104224426
        offset_w: 0
        offset_w: 0
        dst_type: "INT8"
      }
    }
    ```

- Record file for the quantization data equalization preprocessing feature. The content example is as follows:

    ```protobuf
    record {
      key: "linear_1"
      value {
        scale_d: 0.00784554612
        offset_d: -1
        scale_w: 0.00778095098
        offset_w: 0
        tensor_balance_factor: 0.948409557
        tensor_balance_factor: 0.984379828
      }
    }
    record {
      key: "conv_1"
      value {
        scale_d: 0.00759239076
        offset_d: -4
        scale_w: 0.0075149606
        offset_w: 0
        tensor_balance_factor: 1.04744744
        tensor_balance_factor: 1.44586647
      }
    }
    ```

- The channel sparsity record file records the cascade relationship between sparse layers. The file content example is as follows:

    ```protobuf
    prune_record {
      producer {
        name: "conv1"
        attr {
          name: "type"
          type: STRING
          s: "Conv2d"
        }
        attr {
          name: "begin"
          type: INT
          i: 0
        }
        attr {
          name: "end"
          type: INT
          i: 64
        }
      }
      consumer {
        name: "BN_1"
        attr {
          name: "type"
          type: STRING
          s: "FusedBatchNormV3"
        }
        attr {
          name: "begin"
          type: INT
          i: 0
        }
        attr {
          name: "end"
          type: INT
          i: 64
        }
      }
    }
    ```

- The structured sparsity record file content example is as follows:

    ```protobuf
    prune_record {
      selective_prune {
        name: "conv1"
        attr {
          name: "mask_shape"
          type: INTS
          ints: 3
          ints: 3
          ints: 3
          ints: 32
        }
      }
    }
    ```
